# Governance Proposals

Koinos governance system and proposal process.

## Overview

Koinos features on-chain governance that allows the community to propose and vote on blockchain upgrades, parameter changes, and other important decisions.

## Governance System

### Voting Power
- Based on VHP (Virtual Hash Power) tokens
- VHP is obtained by burning KOIN
- More VHP = more voting power

### Proposal Types
- **System Contract Upgrades**: Modify core blockchain functionality
- **Parameter Changes**: Adjust blockchain parameters
- **Fund Allocation**: Distribute Koinos Fund resources

## Participation

### [How to Submit a Proposal](submit-proposal.md)
Learn the process for creating and submitting governance proposals.

### Voting Process
1. **Proposal Period**: Community discussion and refinement
2. **Voting Period**: VHP holders vote on proposals
3. **Implementation**: Approved proposals are automatically executed

## Best Practices

### For Proposers
1. **Engage the community** before formal submission
2. **Provide detailed specifications** and rationale
3. **Consider backward compatibility**
4. **Test thoroughly** on testnet

### For Voters
1. **Research proposals** thoroughly
2. **Participate in discussions**
3. **Consider long-term implications**
4. **Vote responsibly**
