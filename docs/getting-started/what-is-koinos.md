# What is Koinos?

*A developer-oriented overview of the Koinos blockchain platform.*

## Overview

Koinos is a next-generation blockchain platform designed with developers in mind. It provides:

- **Fee-less transactions** through the Mana system
- **Smart contracts** written in familiar languages
- **Modular architecture** for flexibility and upgrades
- **Proof of Burn** consensus mechanism

## Key Features for Developers

### Mana System
Instead of gas fees, Koinos uses "Mana" - a regenerating resource that allows for fee-less transactions.

### Smart Contracts
Write smart contracts in AssemblyScript or other supported languages.

### Modular Design
The blockchain is built with a microservices architecture, making it highly flexible and upgradeable.
