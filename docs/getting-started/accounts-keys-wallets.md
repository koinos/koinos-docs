# Accounts, Keys, and Wallets

Learn about Koinos accounts, cryptographic keys, and wallet management.

## Koinos Accounts

In Koinos, accounts are identified by their address, which is derived from a public key.

### Account Structure
- **Address**: A base58-encoded identifier (e.g., `1DQzuCcTKacbs9GGScRTU1Hc8BsyARTPqe`)
- **Public Key**: Used for verification
- **Private Key**: Used for signing transactions (keep secret!)

## Wallets

### Kondor Wallet

**Kondor** is the primary wallet for Koinos, available as a browser extension.

#### Installation
1. Install from [Chrome Web Store](https://chrome.google.com/webstore) or [Firefox Add-ons](https://addons.mozilla.org/firefox/)
2. Create a new wallet or import existing
3. Secure your seed phrase

#### Features
- Secure key management
- Transaction signing
- dApp integration
- Multi-account support

### Other Wallet Options
- CLI wallet (for developers)
- Hardware wallet support (coming soon)

## Security Best Practices

1. **Never share your private key or seed phrase**
2. **Use strong passwords**
3. **Enable browser security features**
4. **Verify transaction details before signing**
