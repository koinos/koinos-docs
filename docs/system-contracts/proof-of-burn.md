# Proof of Burn

Documentation for the Proof-of-Burn consensus system contract.

## Overview

This system contract implements the Proof-of-Burn consensus mechanism that secures the Koinos blockchain.

## Key Functions

- VHP generation through KOIN burning
- Block production eligibility
- Consensus participation management
- Validator registration and management
