# KOIN and VHP

Documentation for the KOIN token and VHP (Virtual Hash Power) system.

## Overview

This system contract manages the native KOIN token and VHP tokens used in the Proof-of-Burn consensus mechanism.

## Key Functions

- KOIN token operations (transfer, balance, etc.)
- VHP token management
- Burning KOIN to generate VHP
- Integration with consensus mechanism
